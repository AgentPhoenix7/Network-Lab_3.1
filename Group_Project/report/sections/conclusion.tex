\section{Conclusion}\label{sec:conclusion}

We built ARP and proxy ARP in C and ran them on simulated networks. A host asks for a missing MAC address and keeps the waiting packets. When the reply arrives, it sends them. A router can answer for hosts behind it, and the worked example shows this in nine steps and eight frames. Reusing our earlier lab code kept the project small. The web page makes each decision visible. The main gaps are in security and in how the engine handles overload (Section~\ref{sec:analysis}).
